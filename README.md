## Local Setup

> - Create a virtual environment and activate it.

```sh
python3 -m venv venv
source venv/bin/activate
```

> - Install the dependency.

```sh
make dep
```

> - Run the program.

```sh
# Check the ./dataset/* directory.
make run dataset=redwine
```
